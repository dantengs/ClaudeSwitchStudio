# 使用手册

## 1. 安装与首次启动

下载仓库 Releases 中的 EXE 安装包。安装器可选择目录，创建桌面及开始菜单入口，并提供卸载功能。默认优先 D 盘，未找到 D 盘时安装到当前用户的程序目录。安装无需退出 Claude；升级前关闭本工具即可。

首次打开会出现三步指引。可以向前、向后查看，或选择稍后再看；设置中可重新打开。主题和字号与引导状态分别保存，升级不会用安装包里的样例偏好覆盖你的设置。

界面可以在 Claude 工作时只读查看。点击收录、恢复登录或切换提供商时，才会明确提示先结束工作并退出 Claude。工具不强制结束进程。

## 2. 认识账号卡片

| 按钮 | 含义 |
| --- | --- |
| 添加登录 | 发现历史账号，但还没有可用的桌面登录快照 |
| 收录当前登录 | 当前官方桌面身份尚未收录 |
| 更新登录状态 | 当前账号已有快照，可以保存最新本地状态 |
| 切换账号 | 其他账号已有快照，可以在退出 Claude 后尝试恢复 |

邮箱来自 UUID 精确匹配的本地记录或用户确认的对应关系，界面会注明来源。显示名称和邮箱都不是远端身份验证结果。可以起别名，完整邮箱也可以直接作为显示名；内部目录按账号 UUID 生成。

## 3. 收录与切换官方账号

这是未经官方支持的实验功能。启用前请阅读 README 中的账号风险说明，避免使用不可接受损失的重要账号做试验。

在官方 Claude Desktop 自行登录一个账号，完成任务后从系统托盘完全退出。结束 Claude Code 和第三方版。回到本工具点击“收录当前登录”，核对对象后继续。工具会检查当前 UUID 与卡片是否一致，检查本地缓存，先做时间戳备份，再创建受保护的快照。

添加第二个账号时，会提醒先保留当前尚未收录的身份。自行在官方客户端完成第二个账号登录，退出后再收录。官方退出登录可能撤销先前凭证；工具不能保证旧快照仍有效。

两个账号有快照后，退出 Claude，选择目标卡片的“切换账号”。工具会保存当前官方账号的最新状态，避免旧快照遗漏刷新后的令牌，再恢复目标文件。实际能否登录请自行打开 Claude 确认；失效时重新通过官方客户端登录并收录。

只打开终端版 Claude Code 并不会建立 Desktop 登录。两者的认证文件和登录流程独立。

## 4. 第三方提供商

程序只读识别当前用户已有的 CC Switch 桌面提供商配置，不包含 CC Switch 本身，也不提供第三方账号注册。请先在原工具中配置端点与自己的 API 凭证，再在此工具刷新。

选择提供商前，退出 Claude。工具会按时间备份配置，切换本地官方/第三方模式；官方订阅令牌不会作为第三方 API 凭证使用。某些模型映射需要本工具的本地转发器保持运行，端点由用户的提供商配置决定。使用哪个提供商，费用和隐私规则就由该提供商约束。

## 5. 共享池、记忆与用量

共享池从多个账号的本地索引汇总对话，同一份原文只展示一次；不同分支会保留。可以按来源筛选或搜索。未注册原文放在单独分类供核对。

当前版本提供统一浏览视图，不自动把所有账号索引链接到同一目录，也不保证每个 Claude 原生侧栏都显示同样的条目。“共享方案预览”仅检查计划，不移动数据或创建联接。

项目记忆保留在 Claude 的本地项目目录。工具展示位置与文件数量，不把账号登录状态写进记忆。历史缓存/用量来自已有记录，不能据此保证后续对话能沿用服务端缓存。

## 6. 备份与故障

普通完整会话备份包含索引、原文、记忆与相关状态，ZIP 和清单逐文件校验。认证操作另建 `data/private-auth-backups/<时间戳-用途>/`，其中包含敏感登录文件，请勿分享。

Windows 当前用户的 `.claude-profiles/` 保存登录快照和公共操作记录；新版本的认证操作共用文件锁。旧版不认识新的公共锁，请避免在旧、新工具窗口同时操作账号。

如果提示未完成事务，先停止后续切换，保留原文件、隐藏的暂存目录和对应时间戳备份。不要删记录强行重试。认证恢复涉及多个文件及账号/组织状态，应核对清单并由熟悉该客户端版本的人处理。普通会话撤销只适用于本工具记录、校验仍一致的操作。

升级保留运行后产生的 `data/`。卸载只移除安装文件和入口，不删除会话、记忆、账号快照或用户备份。如果要清理敏感数据，应先自行确认备份需求并在官方客户端处理登录撤销。

## 7. 常见问题

**为什么有邮箱却不能直接切换？** 邮箱和历史记录只是账号线索，需要该账号的桌面登录快照。

**为什么打开 Claude Code 仍无法收录？** 工具收录的是 Desktop 本地状态，请在 Claude Desktop 登录。

**为什么恢复后要求重新登录？** 可能过期、撤销、登出、令牌轮换或版本变化。文件完整不代表远端授权有效。

**可以直接在工具里 OAuth 添加多个官方账号吗？** 当前没有。CC Switch 的官方多账号流程委托官方 CLI；不能据此推断 Desktop 也提供同样接口。

**会不会封号？** 无法给出可信概率或保证。只在本地保存不代表已获服务提供方许可；请以官方条款及自己的风险接受程度决定。

**为什么 Windows 提示未知发布者？** 当前版本没有商业代码签名证书。请核对仓库发布来源与 SHA-256；若不信任，先审查源码自行构建。
